[Scene 01 · 铁帷幕号的加压舱]

海水击打在耐压壳上的闷响，像某种潜伏在深海地幔深处的庞大生物在咀嚼岩石。林言将最后一枚钛合金卡扣拧入槽位，指尖传来的金属冷感瞬间浸透了薄薄的防护手套。

“深潜器压力平衡完成，”他低声汇报，喉麦中只有微弱的电流杂音，“外界水深四千两百米，水下裂隙热流正常。但方舟残骸周围的重力波形有轻微偏移。”

[Scene 02 · 裂隙边缘的微光]

探照灯刺破了永恒的纯黑。苍白的锥形光束在浑浊的水体中切开一道路径，照亮了那些自下而上漂浮的有机碎屑。几根从泥沼深处隆起的巨大肋骨状结构，在幽蓝色的浮游光晕中投下长达数百米的阴影。

那不是生物骨骼。那是前纪元人类建造的“迁徙方舟”外壳骨架，表面覆盖着厚达半米的苔藓状硅基共生体。它们以冷却水通道里残留的衰变热为食，在漆黑中散发着有节律的微光，仿佛一道静止在深渊里的呼吸。

[Scene 03 · 机械共鸣]

潜水器继续下降。舱内的警报灯忽然转为了低频的琥珀色。林言的瞳孔猛地收缩，他本能地按下了悬停阀——在前方不到五十米的沉积岩断层上，一扇本该在三百年间被完全封死的压力气闸，此刻正向外吞吐着细密的银灰色气泡。

气泡触及潜水器观察窗的一瞬间，外层的声纳传感器骤然爆发出一阵尖锐的啸叫，紧接着，那声音化作了一段规律而古老的脉冲代码。
